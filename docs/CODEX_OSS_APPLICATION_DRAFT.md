## Project description (English)

Origin Spectra MCP extends the MIT-licensed origin-mcp ecosystem with workflows for XPS and XRD scientific plotting in Origin/OriginPro. It supports data import, validation, editable figures, style presets, and repeatable automation through an MCP interface. The project is intended to reduce repetitive plotting work while preserving the ability to inspect and edit the underlying scientific figures.
