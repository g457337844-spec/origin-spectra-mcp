# Security

This project automates local desktop software with the privileges of the user running it. Run it only with trusted MCP clients, review requested file changes, and keep backups of original research data. Do not expose local control endpoints to an untrusted network.

Report potential vulnerabilities through GitHub private vulnerability reporting when available. If it is unavailable, create a minimal public issue asking for a private contact channel; do not include credentials, private data, or exploit details. No guaranteed response time or security certification is claimed.
